# Machine Learning Lab

Python exercises covering exploratory data analysis and supervised learning with the Iris and Wine datasets from scikit-learn.

## Lab 1: Iris data exploration

`Lab1.py` inspects the Iris dataset, checks data quality, summarizes measurements by species, and plots feature distributions and relationships.

## Lab 2: Wine classification

`lab2.py` explores the Wine dataset, compares feature scaling approaches, and evaluates k-nearest neighbors, logistic regression, and decision tree classifiers.

## Requirements

Install the packages used by the scripts:

```bash
python -m pip install pandas numpy matplotlib seaborn scikit-learn
```

Run either lab with:

```bash
python Lab1.py
python lab2.py
```
